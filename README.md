# راننده تاکسی تهران 🚕

بازی شبیه‌ساز و مدیریت رانندگی تاکسی در تهران — کاملاً در مرورگر، بدون نصب، بدون سرور و بدون هیچ کتابخانه‌ی جانبی.

![نمایی از بازی](assets/screenshot.png)

صبح از خانه می‌زنی بیرون، باک نصفه است و پراید هم حالش خوب نیست. مسافر سوار می‌کنی، از لای ترافیک رد می‌شوی، به موقع می‌رسانی، انعام می‌گیری و کم‌کم از **پراید** تا **شاهین** بالا می‌کشی.

| بخش | توضیح |

## 🕹️ کلیدها

| `←` `→` / `A` `D` | فرمان |
| `Space` | ترمز دستی |
| `H` | بوق |
| `M` | ضبط / آهنگ |
| `C` | کولر |

روی گوشی و تبلت، دکمه‌های لمسی به‌صورت خودکار نمایش داده می‌شوند: فرمان سمت چپ، گاز و ترمز سمت راست.

## 🚀 اجرا روی کامپیوتر خودت

بازی کاملاً ایستا (static) است. کافی است فایل‌ها را روی یک سرور ساده اجرا کنی:

```bash
git clone https://github.com/DashAli10/bazi-taxi.git
cd bazi-taxi
python3 -m http.server 8080
# سپس http://localhost:8080 را باز کن
```

> باز کردن مستقیم `index.html` هم کار می‌کند، ولی برای فعال شدن حالت آفلاین (Service Worker) باید از `http://` استفاده کنی.

## 🌍 انتشار روی GitHub Pages

فایل `.github/workflows/deploy-pages.yml` از قبل آماده است. فقط کافی است:

1. تغییرات را روی شاخه‌ی `main` بفرستی (merge کنی).
2. در گیت‌هاب به **Settings → Pages** بروی و در بخش **Build and deployment** گزینه‌ی **Source** را روی **GitHub Actions** بگذاری.
3. تمام. بازی روی این آدرس منتشر می‌شود:

```
https://dashali10.github.io/bazi-taxi/
```

می‌توانی همان پوشه را روی هر میزبان ایستای دیگری هم بگذاری (Netlify، Vercel، Cloudflare Pages، لیارا، آروان‌کلاد و…) — هیچ مرحله‌ی build ای لازم نیست.

## 📱 نصب به‌عنوان اپلیکیشن (PWA)

بازی یک `manifest.webmanifest` و `sw.js` دارد؛ بعد از اولین اجرا روی `https`، مرورگر گزینه‌ی «افزودن به صفحه‌ی اصلی» را نشان می‌دهد و بازی **آفلاین** هم اجرا می‌شود.

## 🗂️ ساختار پروژه

```
index.html              صفحه‌ی اصلی و کل ساختار رابط کاربری
css/style.css           ظاهر راست‌چین بازی
js/util.js              ابزارهای عمومی (اعداد فارسی، ریاضی، رسم)
js/data.js              داده‌ها: ماشین‌ها، ارتقاها، مسافرها، دیالوگ‌ها و رویدادها
js/city.js              ساخت نقشه تهران، میدان‌ها، نشانه‌ها، ترافیک و مسیریابی
js/entities.js          فیزیک ماشین بازیکن، ترافیک شهری و ماشین پلیس
js/audio.js             صداهای ساخته‌شده با WebAudio (بدون فایل صوتی)
js/render.js            موتور نمایش دوبعدی و نقشه‌ی کوچک
js/ui.js                HUD، دیالوگ‌ها، فروشگاه و پنل‌ها
js/game.js              هسته‌ی بازی: چرخه روز، سفرها، پلیس، اقتصاد و ذخیره‌سازی
js/main.js              ورودی‌ها و حلقه‌ی اصلی بازی
sw.js                   سرویس‌ورکر برای اجرای آفلاین
```

## 🔧 دست بردن در بازی

- **دیالوگ و مسافر جدید:** آرایه‌ی `PASSENGERS` در `js/data.js`
- **ماشین و قیمت‌ها:** آرایه‌ی `CARS` در همان فایل
- **رویدادهای وسط راه:** آرایه‌ی `EVENTS`
- **نقشه شهر:** `VROADS` و `HROADS` در `js/city.js` و توابع `buildSquares` و `buildLandmarks`
- **اقتصاد بازی:** ثابت‌های بالای `js/game.js` (`FUEL_PRICE`، `REPAIR_PRICE`، `MINUTES_PER_SEC`)
